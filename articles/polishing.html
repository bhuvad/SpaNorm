Polishing the fit

Converge every gene to its own optimum with polishSpaNorm() / polish_spanorm()

Polishing takes minutes on a full dataset, so the chunks on this page are shown but not run when the site is built. They assume a normalised object (spe in R, adata in Python) as produced in Get started.

Why polish

SpaNorm() fits all genes in one shared iteratively reweighted least squares (IRLS) loop: one gene-averaged cell weight vector, one convergence check on the aggregate log-likelihood, and coefficients clamped together across genes. For most genes this is indistinguishable from the gene’s own optimum, but a bright, spatially restricted gene can be left well short of it, and its dispersion, estimated at that point, inflated.

polishSpaNorm() (polish_spanorm() in Python) converges each gene separately by damped Newton on that gene’s own penalised negative binomial log-likelihood, then rewrites the normalised assay from the polished coefficients. It maps the SpaNorm model onto the generic problem solved by polishNB() (polish_nb()): the shared library-size coefficient a1 becomes a per-cell offset, the gene mean an unpenalised intercept, and the biology, library-size and batch columns are ridge-penalised exactly as SpaNorm() penalises them.

Options

Argument (R / Python) Choices Effect
psi.method / psi_method "fixed" (default), "profile" "fixed" converges each gene’s mean at the dispersion SpaNorm() estimated and keeps that dispersion. "profile" re-estimates the dispersion by profile maximum likelihood at the converged mean and re-polishes.
ls "fixed" (default), "joint" "fixed" holds the shared a1 at SpaNorm()’s value. "joint" re-estimates it at the optimum of the total penalised likelihood over the polished genes.
cells "all" (default), "fit" Polish on all cells or only on the ones SpaNorm() sampled for the fit.
null TRUE / True (default) Also polish the stored SVG null model so it stays paired with the full fit.
engine "batch" (default), "gene" The batched Newton engine is the only one available on an accelerator.
backend "cpu" (default), "auto", "gpu" Device for the batched engine.
overwrite FALSE / False Allow re-polishing an already-polished fit, starting from the unpolished one kept alongside it.

ls = "fixed" is the default because SpaNorm()’s own a1 is an unweighted mean over genes, whereas the joint estimate is information-weighted and dominated by the brightest genes: it changes the estimand rather than only its precision, and mostly renormalises the shallowest (lowest-library-size) cells.

A gene with no counts in the polished cells, or with none in the polished cells of one batch level, is held out: it keeps its input fit and is flagged as not polished, with the reason recorded. A warning also counts any gene the Newton engine could not polish. In Python the per-gene diagnostics are stored in adata.var (columns prefixed spanorm_polish_, for example spanorm_polish_polished and spanorm_polish_held_out); in R they are the genes data frame in the polish slot of the stored fit.

Polishing and SVGs

The full and null fits must be estimated the same way for the SVG likelihood-ratio test to compare nested models. Either polish before calling SpaNormSVG() (spanorm_svg()), which then polishes the null to match, or call it directly on an unpolished fit and let it pair the null itself. Polishing a fit whose SVG test has already run re-polishes the stored null (null = TRUE) and drops the now-stale SVG statistics with a warning, so rerun the SVG step afterwards.

  • R
  • Python
spe = polishSpaNorm(spe)
spe = SpaNormSVG(spe)
sn.polish_spanorm(adata)
sn.spanorm_svg(adata)

Polishing a generic negative binomial fit

polishNB() (polish_nb()) and nbProfilePsi() (nb_profile_psi()) work on any fitNB() (fit_nb()) model, with an optional known offset and a wide indicator block folded in by a Schur complement (absorb). In R, nbBlockDesign() gives a compact form for a per-group block design. See the reference pages (Python) for the arguments.
