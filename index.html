SpaNorm

Spatially aware library size normalisation, in R and Python

SpaNorm is a spatially aware library size normalisation method that removes library size effects from spatial molecular data while retaining biology. Standard single-cell inspired normalisation is not appropriate for spatial data, because library size is confounded with biology across space (Bhuva et al. 2024; Atta et al. 2024). SpaNorm models gene- and location-specific effects with smooth thin plate spline functions and keeps only the variation unrelated to library size.

This site documents both implementations. The R package SpaNorm (Bioconductor) and the Python package spanormpy (a faithful port working on AnnData) share the same method and the same documentation. Code examples appear in R | Python tabs. Choosing a language in one tab switches every tab on the site, and the choice is remembered.

Install

  • R
  • Python
if (!requireNamespace("BiocManager", quietly = TRUE))
    install.packages("BiocManager")

# release version
BiocManager::install("SpaNorm")
# development version from GitHub
BiocManager::install("BhuvaLab/SpaNorm")
pip install git+https://github.com/BhuvaLab/spanormpy   # for now
pip install spanormpy                                    # once published on PyPI

For a GPU, install the CUDA build of PyTorch first (see https://pytorch.org), then use backend="gpu" or the default backend="auto". Optional extras: pip install "spanormpy[spatial]" for SpatialData input.
